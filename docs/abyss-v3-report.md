# 阿比斯 v3 · 结构重做 + 跑测记录

> 这份文件是「杀戮尖塔式节点图 + 以撒式房间内容 + 搜打撤」定稿后的实测报告。
> 结构按 §13 落地；下面这些数字**覆盖** §13 里对应的旧数值（§13 的规则不变）。

---

## 1. 一局的形状

```
入口(固定) → 第1行 … 第8行（每行 2~3 格，只能往下一格）→ 楼梯
```

- 每层 8 行；楼梯可以下去，也可以爬回来（爬上去要付「上层惩罚」）。
- 格子种类：战斗 / 精英 / 宝物 / 商店 / 补给 / 事件 / 楼梯。
- **氧气是唯一的钟**：进一格烧氧气、越深越贵；撤离也要烧。
- **撤离 = 一键结算**：按走过的行数 + 所在层数算氧气，烧完掷一次「回程出事」，再把包里的东西卖成钱。
- **死了**：包全掉、钱包清零；买下来的永久升级留着。**每局从第 1 层开始。**

## 2. 本轮的数值

| 项 | 值 | 说明 |
|---|---|---|
| 初始氧气 | 100 | 每局重置 |
| 进一格（含楼梯） | `3 + round(行×1.4 + (层-1)×2)` | 第 1 层第 1 行 = 4，第 8 行 = 14；第 2 层每格 +2 |
| 撤离 | `2 + (层-1)×12 + round(行×1.5)` | 第 1 层走满 8 行 = 14；第 3 层第 6 行 = 33 |
| **换层补气** | 氧气补到 **60%**、回 **25% 血** | 本轮关键改动，见 §4 |
| 回程出事 | 概率 `16% + (层-1)×5%`，掉血 `8+4层` / `4+2层` | 越深越容易挨 |
| 视野 | `1 + 灯等级` 行，更远的格子是 `？` | 开局 23 格里 19 格是 `？`（实测） |
| 攻击 | `4 + 磨手等级` | 一个怪 `ceil(血/攻)` 回合，掉血 `攻×(回合-1)` |

**算一遍第 1 层**：8 格 = 4+6+7+9+10+11+13+14 = 74，撤离 14，合计 88 —— 100 的氧气留 12 点余量。
这一层本来就该是「稳过」，紧张感从第 2 层开始：换层补到 60，第 2 层一整层要 90 左右，缺口得靠补给/商店填。

**结论**

- 只走一层（8 行）**稳稳能活着回来**，赚 70–3500（浮动全看宝物）。第 1 层是教学层，不该杀人 —— 现在确实不杀。
- 往下钻**平均 3 层上下就出事**。收费口在换层那一下：第 2 层一整层约 90 氧气，而补气只到 60，缺口靠补给和商店填。
- 最后两轮深潜（21/22 之后）死在**第 4 层入口**和**第 3 层第 4 行**，两次都是**血先见底**（氧气还剩 60 / 18）—— 也就是说到了第 3 层，主要的敌人从氧气变成了路上的怪。
- 记录到的最深一次是**踩上第 4 层**，说明 4 层可达，但从那之后每一步都是纯收益赌命。
- 收益差得很开：一层 68 也有人跑到 4564，靠的是宝物稀有度 —— 这个方差是故意的（搜打撤的爽点就在「这趟值不值」）。

## 3.5 三条硬验证（都是真跑出来的数，不是估计）

**楼梯双向 + 上层惩罚**

```
到楼梯口 floor1 oxy100→83 (row8 花 17)    楼梯面板打开
点往下   floor1→2  oxy 83                  「下了第 2 层」
二层楼梯 oxy 83→63 (row8 花 20，第 2 层每格 +3→ 现为 +2)
点往上   floor2→1  oxy 63→47               「爬回第 1 层 · 烧了 16 氧气」(6 + 层×5)
```

**视野**

```
开局 23 个格子，19 个是 .map-node--hidden，字形全为 `？`
走到第 8 行后 0 个隐藏 → 视野 = 1 + 灯等级 行
```

**死亡（预置钱包 1234、永久攻击 +2）**

```
死前   hp100 money1234 atk6 meta{atk:2}
死后   hp0   money0    atk6 meta{atk:2}   界面：「倒在 1 层。身上掉了 0 件，钱包里的 1,234 也没了。买下来的东西还在。」
点重来 hp100 oxy100 death:false          回到第 1 层、地图重生成
```

## 4. 跑测中改掉的东西（每条都对应一次实测）

| 发现 | 改法 |
|---|---|
| **换层必死**：d1/d2 下到第 3 层氧气就是 0，深潜等于自杀 | 下楼梯把氧气补到 60%、回 25% 血（「往下是祝福」），深潜才成立 |
| 撤离太便宜：第 3 层第 2 行撤只要 6 氧气，深潜零风险 | 撤离改成 `4 + (层-1)×10 + 行×2`，回程要一层层爬 |
| 回程事件与深度无关 | 概率和伤害都按层数长 |
| **开局撞商店没钱**：一局里连着两格商店，兜里 0，白走两格 | 钱 <60 时不再生成商店，换成宝物 / 事件 |
| 隐藏格子和「事件」都用 `？`，点亮后分不清 | 事件改 `✦`，隐藏格保留 `？` + 淡边框（`？` 是「不知道是什么」，本来就该用它） |
| **死在战斗里，死亡界面点不动**：实测 `.fight-calc` 盖在「从入口重来」上面（`elementFromPoint` 拿到的不是按钮），鼠标点了没反应 | `die()` 先把 `[data-fight] / [data-panel] / [data-stairs] / [data-settle] / [data-inspect]` 全撤掉，再弹死亡界面 |
| 楼梯节点白走：不算钱、不进 path、也不烧氧气，8 行其实只收 7 行的钱 | 楼梯并进 `enterNode`，和别的格子一样收费计数 |
| 手机上 200px 的背包把左边那列格子压住 | 窄屏背包默认收起成「背包 4/30」的小夹子，点标题展开 |
| HUD 攻击力买了磨手不刷新 | `data-atk` 跟着 run 状态同步 |
| 面板只能点关闭 | Esc 也能关 |
| 测试器点不中按钮（旧面板还在 DOM 里） | 所有覆盖层关闭时**立刻** `remove()`，选择器一律带 `.is-on` 作用域 |
| **满级了还能再买**：磨手买满 4 档后按钮还亮着，点了扣 900 钱但没效果 | `disabled` 改成每次重画时求值（`() => meta.atk >= 4`），点击前再判一次；氧气/血满时对应的货也置灰 |
| 局内背包扩容用的是打开面板那一刻的尺寸，连买两档只长一格 | 买的时候现取 `bagSize()` |

## 5. 地面补给站（钱花在哪）

撤回来 → 结算面板 → **「地面 · 补给站」**。这里只卖三样，买了就一直在：

| 东西 | 价 | 效果 | 上限 |
|---|---|---|---|
| 磨一磨手 | 900 | 攻击 +1（4 → 8） | 4 级 |
| 换个大背筐 | 1000 | 背包 +1 列（6×5 → 9×5） | 3 级 |
| 更好的灯 | 900 | 视野 +1 行 | 2 级 |

局内的商人卖同样三样，但贵一截（1400 / 1500 / 1400）—— 那是「半路救命」的价钱。
实测（预置 5000 钱跑一轮）：`atk 4 → 8`、`bag 30 → 40`、`lamp 0 → 2`，localStorage 里 `abyss.meta.v3` 落盘正确，下一局开局就带着。

## 0. 先分清两条线（别混在一起看）

| | **线 A · 阿比斯（游戏）** | **线 B · 作品集（网站）** |
|---|---|---|
| 是什么 | 一个想做的游戏 | 个人作品与经历的展示页 |
| 现在的载体 | 网站上的 `/abyss/` 与 `/abyss/dive/` | 首页、作品、文章、时间线、关于 |
| 目的 | 做一个完整作品 | 让别人快速认识我 |
| 状态 | **只有氛围外壳，玩法未定** | 框架完整，内容待填 |
| 谁在用 | 玩家 | 招聘方 / 同行 / 访客 |

**共用资产**
- 一套视觉语言：深色、信号、下潜、米数、记录
- 一个世界观种子：「阿比斯是接进来的一路信号」

**两者的关系**
> 网站上那个阿比斯，是游戏的**先导片 / 概念验证**，不是最终形态。
>
> 它先把气氛做出来，验证「这个味道对不对」，再决定游戏到底做什么。
>
> 所以：**网站上做得再花，也不等于游戏做出来了。** 反过来说，游戏的核心一定能在网站这一点点篇幅里尝到味道，否则说明还没想清楚。

## 2. 线 A · 游戏

### 2.1 还没回答的问题（先列出来，不急着定）

1. **类型**是什么？探索／解谜／叙事／恐怖／下潜模拟？
2. **视角**？第一人称下潜、2D 侧视剖面、还是俯视？
3. **核心循环**：玩家每次下潜要做什么、能带回什么？
4. **深度是资源还是进度？** 有没有氧气／压力的倒计时？
5. **记录是谁写的？** 玩家是继承者，还是作者本人？
6. **「更深处」到底是什么？** 结局是「到底」还是「永远没到底」？
7. **规模**：20 分钟的短篇，还是能做几个月的东西？
8. **引擎**：UE5？Godot？还是继续 Web（Three.js）？

### 2.2 三个可能的方向（备选，都还没定）

#### 方向 1 · 下潜模拟（最贴合现在的氛围）

- 第一人称，操控一台往下的探测器
- **深度就是资源**：下得越深，回程越难，必须在「再往下一点」和「回得去」之间做选择
- 每次下潜带回「记录」，记录拼出真相
- 参考氛围：《SOMA》的孤独 + 《Subnautica》的压迫感，但**去掉生存建造**
- 规模：小而完整，2–4 小时

> 优点：和现在网站的氛围 100% 对齐。
> 风险：第一人称 + 深海 = 最容易做成「走两分钟就腻」。

#### 方向 2 · 剖面解谜（最省成本）

- 2D 侧视，玩家在一条竖井里规划路线
- **现有那条红色崎岖折线本身就是解谜界面**：路线选择决定这一潜看到什么
- 每次下潜是「一局」，可以反复刷不同路线
- 规模：可以做得非常小，甚至网页就能跑

> 优点：成本最低、最快出可玩版本、最能验证核心玩法。
> 风险：容易变成「一关卡一关，没有阿比斯的味道」。

#### 方向 3 · 叙事装置（最接近现在的网站）

- 不是「玩」，是「读」：一个可以反复下潜的叙事空间
- 每次下潜看到不同的记录片段，顺序和深度可变
- 规模：一个月能做完，本质是高级互动小说

> 优点：门槛最低、最容易做完、最容易放进作品集。
> 风险：「互动小说」在作品集里说服力不如「真游戏」。

### 2.3 从网站能直接搬到游戏里的资产

| 资产 | 复用到游戏 |
|---|---|
| 五区域命名 + 深度段 | 直接就是关卡分段 |
| `ROUTE_PATH` 下潜剖面 | 可以变成关卡地图／路线选择界面 |
| 深度 HUD + 危险等级 | 直接就是 UI |
| 三条记录文本 | 直接就是叙事素材（可以扩到 7 条） |
| 雷达扫描 + 回波 | 可以变成「侦测」玩法 |
| 无光带 + 手电筒 | 直接就是光照机制 |
| 音效系统 `sfx.ts` | 直接就是声音设计 |
| 下潜转场 `dive-transition.ts` | 可以直接就是「一潜开始／结束」 |

## 3. 线 B · 作品集：三层想法（先归档，慢慢做）

> 这些是**网站侧**的增强，和游戏无关。别和上面混。

### A 层 · 把下潜变成内容载体

- **深度 = 时间轴**：每 1000 米 = 一年，滚到某层浮现那年的项目与想法
- **沉船 = 作品**：每个作品是海底一个「发现物」，雷达扫到才浮出卡片
- **压力 = 心力**：越深的作品越「重」（投入最大、最难的那个压在最底）

> 意义：把简历从「列表」变成「打捞」，同一批作品两种讲法。

### B 层 · 把「信号」设定做透

- **低频偶发干扰**：任意页面，每分钟最多一次，文字抖一下，浮出「下面还有东西」
- **全站信号强度条**：顶部一条极细的线，越接近 `/abyss/` 越弱
- **404 = 掉进更深处**：「这一段信号丢了」
- **标签页标题衰减**：越往下 `document.title` 越乱、最后变空

> 意义：让整站变成「有世界观」的作品集，而不是「好看的页面 + 一个彩蛋」。

### C 层 · 交互与感官

| 想法 | 说明 |
|---|---|
| **3000 米以下开手电筒** | 无光带之后只有鼠标周围一圈可见（视觉冲击最强的一处） |
| **下潜的抵抗感** | 5000 米后继续滚，页面反向走一点；过 6000 米抵抗消失 |
| **心跳同步** | HUD 心跳从 72 降到 40，用 WebAudio 实时合成低频 |
| **越深越失焦** | 色差、噪点、轻微模糊随深度递增 |
| **氧气倒计时** | 显示「你还能待 N 分钟」，但永远够用（纯心理装置） |

### D 层 · 内容型玩法

- **7 条记录做满**（现在只写了 3 条：01 / 07 / ?）
- **收集解锁「更深处」**：集齐才开门，而不是永久死锁
- **和文章页联动**：读完所有文章才能下到 8000 米（`articles-unlock.ts` 已存在）

### E 层 · 技术炫技（风险最高，慎入）

- **Canvas 深海粒子**：洋流、发光生物、浮尘。纯 canvas 就够，别上 three.js
- **真 3D 竖直隧道**：Three.js 相机下降。**建议不做**——移动端会掉帧，作品集不需要

## 5. 一条设计原则（写给未来的自己）

> **别让阿比斯比内容精致太多。**

访客点进来，第一眼会被阿比斯震到；第二眼发现「作品」栏还是占位符，印象会立刻从「这人很牛」变成「这人很闲」。

所以每次想给阿比斯加特效之前，先问一句：**作品页填满了吗？**

## 8. 站点骨架（v0.2 · 这一版只定结构，不定内容）

> 要解决的问题：现在下潜是「滚着看风景」，到 1,500 米突然跳出一张牌桌，
> 两套视觉语言硬拼在一起。改完之后，平台不是弹窗，是路上一块被照亮的岩架。

### 8.1 两种输入，同一时刻只有一种有效

| 输入 | 什么时候有效 | 干什么 |
|---|---|---|
| **滚轮** | 行进段 | 走。下潜 / 上浮都是它，玩家全程自己控制 |
| **拖卡** | 平台段 | 做事。所有动作都是「把一张卡叠到另一张卡上」 |
| — | 平台段 | 滚轮变成**软阻力**：动一点点、弹回来，不通就是不通 |

「交互统一」守的不是「只能用拖卡」，而是：**任何时刻，只有一种输入是有意义的**。
站着不走路，走路不做事——两者在时间上不重叠，所以不算缝合。

### 8.2 段落表

| 段落 | 输入 | 桌上/路上 | 产出 |
|---|---|---|---|
| 站 0 · 0 米 | 拖卡 | 角色卡 + 入口卡 | 教会「叠卡」 |
| 行进 0 → 1,500 | 滚轮 | 记录 01、肉眼可见的上浮物 | 到站 |
| 站 1 · 1,500 岩架 | 拖卡 | 角色 + 岩壁 + … | 把入口弄通 |
| 行进 1,500 → 3,000 | 滚轮 | 记录 07、剪影 | 到站 |
| 站 2 · 3,000 回声带 | 拖卡 | 待设计 | 待设计 |
| 行进 3,000 → 5,000 | 滚轮 | 无光带，雷达上线 | 到站 |
| 站 3 · 5,000 压密层 | 拖卡 | 待设计 | 待设计 |
| 行进 5,000 → 7,000 | 滚轮 | 雷达失真 | 到站 |
| 站 4 · 7,000 底 | 拖卡 | 待设计 | 待设计 |

每层平台只干三件事：**看清这层有什么 → 做 1~3 个动作 → 把入口弄通**。

### 8.3 状态机

```
        ┌──────────────── 滚轮 1:1 ────────────────┐
        ↓                                          │
   [ TRAVEL ] ──接近站(900px)──> [ APPROACH ]        │
        ↑                            │ 减速 1→0.45  │
        │                            ↓              │
   [ PUSH ] <──入口通了──────── [ SETTLE ] ──> [ BOARD ]
        │                            ↑               │
        └──── 0.4s 加速推一把 ────────┘               │
                                     └── 滚轮：软阻力 ─┘
```

- `TRAVEL`：滚轮直接驱动行程，所见即所得
- `APPROACH`：只改「滚轮位移 × 衰减系数」，不改视觉。世界看起来在减速靠岸
- `SETTLE`：吸附到精确落点（二分求出来的那个位置），0.18 秒 6px 回弹 + 一声闷响
- `BOARD`：拖卡。滚轮改成软阻力（最多溢出 ~120px，弹簧拉回）
- `PUSH`：入口通了之后的第一格滚轮，自动额外推 5% 屏，0.4 秒 ease-out，然后交还

### 8.4 过渡四拍（时序）

| 时刻 | 发生什么 | 时长 |
|---|---|---|
| 靠岸 | 离站 900px 起，滚轮位移按 smoothstep 衰减到 0.45 | 随玩家 |
| 落定 | 吸附 + 6px 回弹 + 一声低闷响 | 180ms |
| 照亮 | 岩架那块**局部光池** 0→1（不是全屏遮罩） | 450ms |
| 落卡 | 每张卡间隔 80ms，从 +14px 淡入并转正 | 320ms/张 |
| 离站 | 入口卡裂开变亮 | 300ms |
| 蹬离 | 首格滚轮额外推 5% 屏 | 400ms |

要点：**背景不清空**。路线、深度表、暗处的上浮物继续慢慢地动，人会觉得世界还在，
只是我停在了这块岩架上。

### 8.5 技术上必须换掉的一件事：原生滚动

原生滚动做不了三件事——靠岸减速、站内软阻力、蹬离加速，也做不了设计文档
§3-C 里早就写下的「5,000 米后继续滚，页面反向走一点」。

所以改成**虚拟滚动**：

```
wheel(delta) → target += delta → pos += (target - pos) * k → window.scrollTo(0, pos)
```

渲染层一行不用改：`getBoundingClientRect`、sticky、progress、折线、雷达全都照旧，
只是「谁在改 scrollY」从浏览器换成了我们。

需要顺手处理：隐藏滚动条、关掉 `scroll-behavior: smooth`、键盘（空格/PageDown 映射成固定一跳）、
刷新恢复位置。

### 8.6 深度决定「你怎么看见」

| 深度 | 怎么看 | 看到什么 |
|---|---|---|
| 0–1,500 | 肉眼看，有光 | 上浮的水母、羽状物、气泡；有颜色 |
| 1,500–3,000 | 肉眼看不清 | 只剩剪影，褪成灰蓝，更少更慢 |
| 3,000+ | 肉眼全黑，**雷达** | 每次扫过，上浮物亮 0.6 秒就散 |
| 5,000+ | 雷达也失真 | 拖尾变长、扫描变慢，形状不对 |
| 7,000+ | 底 | 一次很长很慢的弧，然后停 |

这条是「中间得有意思」的主体：上浮物的方向和人**相反**（往上走），
越深越只能靠回声猜——「看见」从清楚变成拼凑。

### 8.7 卡的视觉：从「纸卡」改成「被深渊照亮的东西」

现在卡是奶油色纸片 + 硬投影，跟世界的雾、暗、渐变完全两套语言，这是「缝合感」的根。

| 部位 | 现在 | 改成 |
|---|---|---|
| 卡面 | `#f0e8d8` 纸 | `#191821 → #12111a` 暗石板 |
| 边 | 2px 纯黑 | 1px 细边，左上暖、右下暗（光从上来） |
| 字 | 墨黑 | 骨白 `#efe3cf`，副行 `#a89a86` |
| 图标 | 深褐线稿 | 淡金线稿 `#d9b98a` |
| 血条 | 亮红 | 暗琥珀，掉血才亮 |
| 投影 | 死黑 | 极淡暖色边缘 + 短黑投影 |

风险：暗卡贴在近黑的底上容易糊。补偿办法是**卡底下一小团更亮的地面**（不是光晕，是「被照到的那块岩架」），
以及卡面比背景固定亮一档。

## 9. 这个游戏和站点的隔离（重要）

阿比斯是站点上的一个小模块，**随时可以被关掉或整个拆掉，而站点一行都不用改**。

### 9.1 三层保护

| 层 | 做了什么 | 效果 |
|---|---|---|
| **样式** | 游戏样式全在 `src/styles/abyss.css`，只有 `/abyss/` 和 `/abyss/dive/` 两个页面 import | 游戏样式写崩了，最多那一页难看；别的页面根本不加载这个文件（构建产物里是两个 CSS） |
| **脚本** | 游戏脚本只在两个 abyss 页面里 import | 别的页面不下载、不执行 |
| **开关** | `src/consts.ts` 的 `ABYSS_GAME` | 设成 `false`：游戏整块不渲染，页面只剩「信号中断」，首页菜单那一项也一起收起；所有游戏模块第一步检查 DOM，没有就退出，不跑逻辑不报错 |

### 9.2 一行关掉

```ts
// src/consts.ts
export const ABYSS_GAME = false;
```

关掉之后：
- `/abyss/dive/` → 「这一段暂时没有信号」
- `/abyss/` → 「信号中断」，下潜按钮没了
- 首页菜单 → 「阿比斯」那一项连同右侧图标一起消失（其余四项不变）
- 游戏 JS 仍会下载，但立刻退出；**不会隐藏滚动条、不会接管滚轮、不会报错**

> 注意：这个开关管的是「跑不跑」，不是「编不编」。如果游戏代码本身编译不过，
> 整个 build 会失败（GitHub Pages 会保留上一版，站不会挂），那种情况只能修或者按 9.3 删掉。

### 9.3 拆除清单（五分钟）

按顺序删，删完 `npm run build` 应该照样通过：

1. `src/pages/abyss/`（两个页面：入口 + 下潜）
2. `src/scripts/abyss/`（`stations.ts`、`virtual-scroll.ts`、`drift.ts`）
3. `src/scripts/station.ts`
4. `src/styles/abyss.css`
5. 首页 `src/pages/index.astro` 菜单数组里的最后一项 + `iconAll` 里的最后一项
6. `src/consts.ts` 里的 `ABYSS_GAME`、`ABYSS_META`、`ABYSS_ZONES`、`DIVE_COUNTER`

**别删**：`src/scripts/dive-scroll.ts` 和 `.dive` 那套样式——`/brief/` 也在用，
它们属于站点，不属于游戏。

### 9.4 自动检查

`npm run check` 会跑 `scripts/check-isolation.mjs`，任何一条不过就不让发：

- 游戏目录之外，没有文件 import 游戏模块
- `global.css` 里没有一条游戏选择器（`.pcard` / `.station` / `.drift` / `.dive-route` / `.dive-radar` / `.abyss-` …）
- `abyss.css` 里没有裸的 `html` / `body` / `:root` / `*` 规则

部署流程里 `npm run check` 排在 build 前面，所以**游戏渗回站点会被 CI 拦住**。

## 12. 生命、死亡、撤离（v1.0 · 2026-10-29）

### 12.1 生命

- **上限 100**（以后由装备 / 技能 / 特质改这个数）
- 掉血来源：**上浮**（已接）、战斗（魔塔式，未接）、事件（未接）、**食物**（有回有毒，未接）
- 左下角一条常驻生命条，低于 30% 会闪红

### 12.2 上浮扣血

按层查表，**只结算净值**——滚下去不扣，滚上来才扣，来回抖动不重复扣。

| 层 | 每 100 米 | 从这层底爬回地面 |
|---|---|---|
| Ⅰ | 0.3 | 4 |
| Ⅱ | 0.7 | 12 |
| Ⅲ | 1.1 | 58 |
| Ⅳ | 1.8 | 148 ← 回不来了 |

分界线在**四层中段**：那以下自己爬是爬不回去的，只能找哨站。

### 12.3 哨站（撤离点）

位置照原作，一共 6 个，**七层没有**。

| 哨站 | 深度 | 撤离价 | 是不是基地 |
|---|---|---|---|
| 石之舟 | 600 | 5 | 落脚点 |
| 监视基地 | 2,540 | 15 | **基地**（进来回 8 血） |
| 被囚禁的海盗船 | 4,000 | 28 | 落脚点 |
| 娜娜奇的秘密基地 | 7,500 | 55 | **基地**（回 8 血） |
| 前线基地 | 12,800 | 80 | **基地** |
| 生骸村 | 14,000 | 92 | **基地** |

哨站上的两张路卡：**下潜口**（继续往下）、**回程**（付撤离价，直接回奥斯）。

从站上**往上滚**也能走（`LEAVE_UP` 60px 就放行），那是徒步上浮，按表扣血。

### 12.4 死亡

血归零 → 全屏红黑 → 「你没能上去」→ 背包**主格全掉**（贴身袋留着）→ 点「回奥斯」→ 回水面。

### 12.5 一个还要定的口子

**回奥斯会回满血**。所以撤离价现在其实是一道「门槛」——血不够就走不了，而不是真扣。
如果想让撤离价真的疼，就改成「回城不回血，只有营地休息才回」。这条没定。

### 12.6 手感三改（v1.1）

| 改了什么 | 为什么 |
|---|---|
| **滚轮 × 0.34** | 2 万米的路按 1:1 走，一格滚轮一百多米，太粗。现在一格约 30 米（贴着站时更少） |
| **到站不自动进** | 原来滚到落点会被拽进牌桌。现在只在下方浮出「进入 · 石之舟」，点才进，滚过去也行 |
| **物品占格有大小** | 学了竞拍之王：占格真的会挤（详见 §12.8） |

顺带：记录文字的显示窗口改成按「米」算（±400 米）——原来按进度算，
深度扩到 2 万米之后开场那段字会一直飘到一千多米。

### 12.7 搜索点挪到路上（v1.2）

搜索点不再挂在站点上，改成按**深度**钉在路线里（`abyss/field.ts`）：

- 每层每 400~700 米一个，滚到附近就从下面浮上来，走远了淡下去
- 点它读秒（1.2s / 2.4s），读完掉 1~3 件在它旁边，先问号再揭
- 东西是**屏幕坐标**的方块，直接拖进左边背包
- 滚过去了就沉回黑里——想回头搜得往上爬，而往上爬要掉血
- 回奥斯会把搜过的点重置

站点桌上只剩三张卡：**人 / 下潜口 / 回程**。

### 12.8 物品尺寸重做 + 背包缩小（v1.3）

**为什么要改**：原来最大只有 2×3，背包又是 10×10 一百格，捡什么都能装下——
于是「整理背包」这件事在游戏里根本不存在。

**尺寸不再是稀有度**。`abyss/loot.ts` 里 `w`/`h` 各 1~4，稀有度 `tier` 单独一栏：
千人楔 1×1 却是稀有，鳞伞 2×3 只是史诗，小石棺 4×4 是传说。

| 尺寸 | 格数 | 现在池子里是谁 |
|---|---|---|
| 1×1 | 1 | 碎瓷片 / 锈铁钉 / 贝壳 / 玻璃珠 / 白垩块 / 星之罗盘 / 太阳玉 / 千人楔 / 观测不可见光的眼镜 |
| 1×2 | 2 | 海藻 / 密封罐 / 制造水的杯子 / 切割钢铁的剪刀 / 延长寿命的酒 |
| 1×3 | 3 | 断绳 / 绝对无法切断的线 / 断裂的长矛 |
| 2×2 | 4 | 光明砂 / 风信鸡 / 无尽锤 |
| 2×3 | 6 | 兽皮 / 雾织纱 / 鳞伞 |
| 3×2 | 6 | 生命回响之石 |
| 3×3 | 9 | 免除诅咒的篮子 / 停止时间的钟 |
| 4×4 | 16 | 小石棺 / 精神隶属机 |

**大件分深度出现**（`minDepth`）：3×3 从 2,600 米起，4×4 的石棺 7,000 米、隶属机 12,000 米。
浅处抽不到，不是运气问题——是真没有。

**背包默认 6×5 = 30 格**（`abyss/bag.ts`），另加贴身袋 2 格（1×1 才塞得进）。

- 一件 4×4 吃掉 16 格，塞进去就装不下第二件大东西
- 三件 2×3 就把主格占掉大半
- 于是「先捡小的把缝填满，还是清空去背那件大的」成了每趟都要做的决定

**地上那件东西也按尺寸长个儿**：边长 = 28 + 长边×7 px，右下角标 `2×3`。
拖之前就知道要不要先腾地方，不用来回试。

顺带修掉的两件：

- 进站时把路上的搜索点整层收起来（`.field--hidden`），不再和站里的牌抢点击
- 搜完点掉出来的东西往下让 38px，不压在「空了」的搜索点上

**还没做**：物品价格 / 卖出 / 市场波动。定价必须先有尺寸表——现在有了。

### 12.9 价格照原著的遗物等级（v1.4）

**一条铁律**：价格是**物品自己的属性**。星之罗盘在 600 米捡到和在 19,000 米捡到，卖的
都是 180——不按深度加价，不按层数打折，不随机浮动。深度只决定「能遇到什么」。

**等级表**（`abyss/loot.ts` 的 `rank`，日文原名照原著）：

| 我们叫 | 日文原名 | 价格 | 占格 |
|---|---|---|---|
| 杂物（不是遗物） | — | 1 ~ 24 | 1×1 ~ 2×3 |
| 四級遺物 | 星の羅針盤 / 太陽玉 / うろこ傘 | 150 ~ 220 | 1×1 / 2×3 |
| 三級遺物 | スミ砂 / 霧織り | 380 ~ 420 | 2×2 / 2×3 |
| 二級遺物 | 天気を当てる風見鶏 / 命を響く石 | 900 ~ 1,400 | 2×2 / 3×2 |
| 一級遺物 | 鉄を切る鋏 / 見えない光を見る眼鏡 / 水を生む盃 / 千人楔 / 呪い除けの籠 / 無尽鎚 | 2,600 ~ 6,000 | 1×1 ~ 3×3 |
| 特級遺物 | 時を止める鐘 / 決して切れない糸 / 命を延ばす酒 / 精神隷属機 | 8,500 ~ 40,000 | 1×2 ~ 4×4 |
| 不明遺物 | （等级不明，得卖出去才知道） | 600 ~ 18,000 | 1×1 ~ 4×4 |

等级摘自设定 wiki 的[遗物一览（等级顺）](https://wiki3.jp/miabyss-matome/page/13)。
几条**故意反着来**的坑，都是原著本身就这样的：

- **星之罗盘只是四級**，180 块；可它是全作最有名的一件
- **鳞伞占 2×3，只值 150** ——背它等于用半个主格换两个绷带钱
- **千人楔 1×1，4,500** ——巴掌大的铁楔子顶一整趟
- **小石棺 4×4 却「不明」** ——值多少？卖出去那一下才告诉你

颜色也跟着改成六档：白（杂物）/ 绿（四級）/ 蓝（三級）/ 紫（二級）/ 金（一級）/ 红（特級）。
红色以前没用过，现在专给特級。

**结算**（`abyss/settle.ts`）：回到 0 米或付钱撤离时，背包整包交给交易所：

- 一件一件列出来：图标 / 名字 / 等级 / 占格 / 价钱，按价钱从高到低
- 没鉴定的遗物在这一下**当场揭晓**（标个「鉴定」），你才知道自己背回来的是什么
- 合计进钱包，钱包写 localStorage，死了不清零、刷新不丢
- 死了不结算——东西已经掉在水下了

**画面**：左下角除了生命条，多一个「所持」；背包标题右边是这一包的估价（`≈2,380`，
里面若有没鉴定的东西就写成 `≈2,380+`，因为那几件的价还不知道）。
顺手修了个一直在的老问题——生命条原来绑在 stage 底边，开场 stage 还没贴住顶，
整条被裁在屏幕外，现在改成 `position: fixed`。

**还没做**：钱现在只能攒，不能花。下一步要么「营地的仓库/鉴定/制造」，要么「食物与消耗品补给」，
总得有个地方让钱出去。

### 12.10 东西要看得懂（v1.5）

以前地上只有图标和颜色，包里只有方框——「要不要背」这件事不成立，因为没有信息。

**地上那件东西改成一张卡**：图标 / 名字 / `2×3` / 价钱。
没鉴定的遗物写「？？？」和「？」，因为它值多少你还不知道——这是故意的。

**点一下就能看到详情**（`abyss/inspect.ts`，照三角洲的物品逻辑）：

| 栏位 | 内容 |
|---|---|
| 名字 + 等级 | `千人楔` / `一級遺物`；未鉴定写 `？？？` / `未鉴定` |
| 类型 | 遗物 / 材料 / 工具 / 食物 |
| 占格 | `1×1` ~ `4×4` |
| 估价 | 固定价钱；未鉴定显示 `—` |
| 描述 | 一句话，写它在原著里是个什么东西 |
| 按钮 | 只有能用的东西才有：`吃下去 · 回 6` |

背包和地上都能点开（两边都只是往 window 上抛 `loot:inspect`，不用互相 import）。
点一下=看，拖走=挪位置，两者靠「有没有移动超过 5px」区分。

现在池子里的 31 件东西都有种类和描述；能吃的两件：**海藻**（回 6）、**延长寿命的酒**（回 30）。

## 13. 下一步：危险从哪来（还没定，下面是提案）

问题：现在从水面到 8,000 米只是「滚轮转几下」，没有任何代价，所以不像在冒险。

原设定里能直接借的两样：

- **遗物等级**（特級~四級 + 不明）→ 已经用在价格上
- **原生生物危険度**（[★1~★7 + 危険度不明](https://wiki3.jp/miabyss-matome/page/20)）→ 用来当怪物的评级，
  而且原作里 ★6「桁外れ」和 ★7「空前」两档**标注「未登场」**：深处的评级根本没人写出来过

### 13.1 提案：能见带 + 拖卡接敌 + 守门兽

| 层 | 怎么做 |
|---|---|
| **怪怎么出现** | 主：在**能见带**（前方 ±120 米，复用现有的 drift/radar）里游动，用和背包同一套格子：小兽群是几块 1×1，巨兽是一整块 3×3/4×4 |
| **你知道什么** | 只知道体型和动作。**没有评级**——除非你活着见过它（以后接图鉴） |
| **怎么接敌** | 拖着「人」叠到它身上=开打（和站里拖卡一致）；不碰=路过，但离得越近/体型越大，被它先发现概率越高 |
| **守门** | 每层入口一只固定的大东西，不追人，但你要选：打过去，还是花血绕 |
| **战斗** | 魔塔式：怪是若干张卡，1×1 小兽群=多张小卡，4×4 巨兽=一张大卡；血量和攻防按体型×评级 |

排除掉的：雷电式鼠标操（鼠标已被拖卡占用）、宝可梦区域触发（切断纵向连续感）、天数倒计时（和「慢慢搜」打架）。

### 13.2 提案：灯（时间就是距离）

不用天数。深渊里本来就得带灯，越深越黑（已有 `--dark`）。

- 灯油按**下潜距离**烧：100 米烧一格
- 烧完 = 看不见搜索点、怪更近才发现、能见带变窄
- 往上走不烧油（往上扣的是血）

### 13.3 提案：让 8,000 米不像「几下滑轮」

1. **每层单独定长**：一层 ≈ 6 屏、七层 ≈ 40 屏，越深越走不动
2. **每 500 米一个路口**：滚到底不许直接过，先选（下潜 / 搜刮 / 埋伏 / 上浮），选择要花灯油或血
3. **三层起徒步上不来**：把「必须靠哨站撤离」提前，先让人怕

待定：这三条挑哪几条、以及怪物要不要**真的能打**（先做一只 ×1×1 的，把战斗跑通再说）。

### 12.11 补给与出发准备（v1.6）

学的是《暗黑地牢》的补给设计（[Light Meter](https://darkestdungeon.wiki.gg/wiki/Light_Meter)、
[各类补给的用途](https://gamerant.com/darkest-dungeon-best-provisions-each-location/)）：

- **每样补给对着一种可预见的麻烦**：饿、渴、黑、伤、断层
- **补给占格子**，和战利品抢空间——这才是「准备」的压力来源
- **没带也能走**，但代价是血
- 补给按「打算下到第几层」给推荐配置，一键买齐

**六样东西**（`abyss/loot.ts` 的 `PROVISIONS`）：

| 补给 | 麻烦 | 占格 | 买价 | 用下去 |
|---|---|---|---|---|
| 干粮 | 饿 | 1×1 | 120 | 饥 +25 |
| 水 | 渴 | 1×1 | 60 | 渴 +25 |
| 医疗包 | 伤 | 1×2 | 400 | 回 15 血 |
| 灯火 | 三层以下的黑 | 1×1 | 300 | 每进一层自动烧一支，没有掉 6 血 |
| 绳索 | 断层 | 1×2 | 250 | 留给以后的断层，现在只是背着 |
| 硬口粮 | 半路饿死 | 1×1 | 800 | 饥 +45 |

**补给卖不回去**（`sell: 0`），结算时不换钱——买多了就是白扔，这是刻意的。

### 12.12 饥与渴（v1.7）

一开始做成了「每 800 米自动吃一份」，太像自动扣税。改成两条值，**吃什么、什么时候吃，玩家自己决定**：

| 值 | 范围 | 掉法 | 归零以后 |
|---|---|---|---|
| 饥 | 0~100 | 每走 100 米 -2（**上下都算**） | 每 100 米 -2 血 |
| 渴 | 0~100 | 每走 100 米 -2 | 每 100 米 -3 血 |

100 点 = 5,000 米的路。所以「来回一趟」比「单程」贵一倍——这就是补给要按两趟买的原因（出发准备里
的推荐数量就是按 `深度×2` 算的）。

**手动吃**：左下角「饥 / 渴」两条下面有四个按钮（干粮 / 水 / 医疗包 / 硬口粮），点一下就吃一份；
背包里点开物品也有同一个按钮。灯火是唯一的自动消耗（三层起每进一层烧一支）。

**走过的路要算，瞬移不算**：撤离和回城会把位置直接搬回水面，那不是「走」。所以单帧位移超过
1,200 米就当成瞬移跳过——不然一撤离就会被判成走了六千米，当场饿死（这个 bug 真踩了）。

### 12.13 每层定长（v1.8）

**问题**：20,000 米被平均铺在整条路上，一层只占一屏多一点——滚两下就到 8,000 米了。

**改法**：给每层一个 `screens`（占几屏），深度 ↔ 路线位置改成**分段线性**（`abyss/metrics.ts`）：

| 层 | 深度 | 屏 | 每屏米数 | 累计到第几屏 |
|---|---|---|---|---|
| Ⅰ | 0–1,350 | 5 | 270 | 5 |
| Ⅱ | 1,350–2,600 | 5 | 250 | 10 |
| Ⅲ | 2,600–7,000 | 8 | 550 | 18 |
| Ⅳ | 7,000–12,000 | 8 | 625 | 26 |
| Ⅴ | 12,000–13,000 | 4 | 250 | 30 |
| Ⅵ | 13,000–15,500 | 6 | 416 | 36 |
| Ⅶ | 15,500–19,500 | 8 | 500 | 44 |
| Ⅷ | 19,500–20,000 | 2 | 250 | 46 |

整条路从 19 屏变成 **46 屏**（页面高度 47 屏，滚动的部分是 46 屏）。一层现在要走 5 屏——
以前只要 1.2 屏，所以「到 8,000 米」变成了一件真的要花时间的事。

**每屏多少米不一样**，这是刻意的：一层一屏 270 米（慢、密），四层一屏 625 米（空、快）。
改 `screens` 一个数，整条路、右侧刻度、哨站落点、搜索点位置全部跟着重算。

**右侧刻度不再等分**：以前是 flex 等分，现在每个刻度按 `sankFromDepth(深度)` 定位
（0 / 21.74% / 39.13% / 56.52% / 78.26% / 100%）。

**踩过的坑**（记下来，别再犯）：

1. **不要用 PowerShell 改源码文件**。`Get-Content -Raw` + `WriteAllText` 把 `consts.ts`、
   `run.ts`、`supply.ts`、`drift.ts` 的中文全写成了乱码，只能从上一版 `dist/` 的 bundle 里捞回来重写。
   改代码一律用编辑工具，别走 shell。
2. **`dive-scroll.ts` 是 /brief/ 和 /abyss/dive/ 共用的站点脚本**，按隔离规矩不能 import 游戏模块。
   所以换算函数由游戏这边挂到 `window.__diveDepth` 上，那边「有就用，没有就线性」。
3. `metrics.ts` 会被 `dive.astro` 的 frontmatter 引去算刻度位置（服务端），所以它碰 `window`
   的地方必须先判断 `typeof window !== 'undefined'`。

### 12.14 路上的东西与战斗（v1.9）

**名字和危险度照原作**（[原生生物一覧(危険度順)](https://wiki3.jp/miabyss-matome/page/20)）：

| 名字 | 危险度 | 体型 | 血 / 攻 | 层 |
|---|---|---|---|---|
| 土嘴 | ★ 軽微 | 1×1 | 6 / 1 | Ⅰ |
| 浜白 | ★ 軽微 | 1×1 | 4 / 1 | Ⅰ |
| 号吼 | ★★ 要警戒 | 2×1 | 14 / 2 | Ⅱ |
| 乙羽 | ★★★ 深刻 | 2×2 | 24 / 3 | Ⅲ |
| 泣骸 | ★★★ 深刻 | 2×2 | 28 / 4 | Ⅲ |
| 紅口縄 | ★★★★ 致命的 | 3×2 | 40 / 6 | Ⅳ |
| 喰怨語 | ★★★★★ 理不尽 | 3×3 | 70 / 9 | Ⅴ |
| 魂疑 | ★★★★★ 理不尽 | 4×4 | 110 / 12 | Ⅵ |
| 未记录 | ★7 空前 | 4×4 | 150 / 16 | Ⅶ |

★6「桁外れ」和 ★7「空前」原作里标注**未登场**，所以七层那只叫「未记录」——档案里这一格是空的。

**它们怎么出现**：钉在某个深度上（每 700~1,100 米一只），在带子里慢慢横着游。
卡片只写体型，**名字是「？？」**，危险度不显示——你只知道它多大。

**两个选择**：

- **点它** = 开打
- **不理它、直接滚过去** = 挨一口（它的攻击力），然后卡片变暗

被咬过、或者跟它打过一次，卡片上才会写出名字和危险度——「拿命换情报」这件事先这么落地（图鉴以后再说）。

**战斗是魔塔式的**（`abyss/fight.ts`）：点一下 = 一回合，你先手，它没死就还手。

```
回合数   = ceil(它的血 / 你的攻 4)
你会掉血 = 它的攻 × (回合数 - 1)     // 最后一回合它已经死了，没机会还
```

所以开打之前就能算清这一架值不值：面板上直接写着「这一下要打 4 回合，你会掉 6 点血」，
打不过就红字标「打不过」。**没有随机数**——伤血是确定的，要不要打是玩家的事。

- 赢了：掉 1~2 件战利品（按当前深度抽），直接进背包，格子不够就只捡得下几件
- 退：挨一口它的攻击，然后这一趟它不会再咬你
- 血被打光：走原来的死亡流程（东西掉在深渊里）

**踩的坑**：路上的卡片每帧都在轻微漂移，`click` 事件要求「按下和抬起在同一个元素」，
漂移会让它不触发。改成监听 `pointerdown`，顺便把漂移幅度从 3% 收到 1.2%。

### 12.15 「你」在哪（v2.0）

以前「你」只是个隐含概念：搜索点和生物都摆在屏幕正中那条带上，但屏幕上没有任何东西
代表你。于是看什么都像**上帝视角**——知道哪只怪几血，却不知道自己站在哪。

现在画出来（`abyss/self.ts`）：

- **场景正中一个「你」**，外面一圈光
- **右边那条剖面上，红点旁边标一个「你」**

光圈半径分三种：

| 情况 | 半径 | 读法 |
|---|---|---|
| 水面 / 三层以上（还有天光） | 240px | 看得见一大片 |
| 三层以下 · 带灯 | 200px | 灯就是这么大一圈 |
| 三层以下 · 没灯 | 92px | 只剩脚下一小块 |

这条线顺手定了一个设定上的取舍：**深度是确定的，水平位置是不确定的**。
你有深度计（右边的读数和红点），但你不知道自己在横向上走到哪儿了——
原作里连罗盘都指不到北，这是应该的。

**这圈光就是视野的骨架**：圈外的东西下一步就该看不见、或者只剩轮廓。
所以视野不是从零开始做，而是把这个圈做实。

还在水面看记录的时候不画「你」——压在大标题上太碍事（`data-off`）。

### 12.16 待办：怪还没有「追」和「逃」（未做，等设计）

**现状（这一版就是这么简陋）**：

- 怪钉在一个深度上，在带子里**横着轻轻漂**，不追人、不逃、不互相影响
- 玩家的选择只有两个：点它（打）／滚过去（挨一口）
- 所谓「躲」其实是**自动挨一口**，玩家没有任何操作空间

**病根**：现在世界里只有**纵向**一个维度。搜索点和怪都锚在「深度」上，玩家锚在屏幕正中，
所以「靠近」只有一种含义——深度差变小。**而「躲」需要「错开」**，也就是第二个维度。
没有横向空间，躲就不成立，只能变成一次固定扣血。

**三条路（还没选）**：

| 方案 | 怎么做 | 代价 | 会变成什么 |
|---|---|---|---|
| A · 世界上走格子 | 整条路变成格子地图，人在格子上走 | 最贵：深度↔格子要重新映射，滚轮下潜这套全得重做 | 变成魔塔／地牢，**丢掉「下潜的距离感」** |
| B · 遭遇时走格子 | 世界还是纵向；**撞上才切进一块局部棋盘**（7×7 左右），你在棋盘上走位 | 中：多一个遭遇子系统，但复用现有的格子语言 | 魔塔的战斗真正成立：**躲 = 走到它够不着的地方** |
| C · 加几条车道 | 带子分成 3~5 条横向车道，按 A/D 或拖拽换道 | 最低：只加一个 x 坐标 | 变横版跑酷，躲靠反应快，靠不住「算」 |

**我倾向 B**：世界保持纵向（距离=时间=补给，这是现在最值钱的东西），
**把「躲」搬进遭遇板**——巨兽占掉一整排，小兽群只挡两格，绕不绕得过去一眼能算出来。

**怪的行为原型（照原作，还没做）**：

| 原型 | 谁 | 行为 | 玩家该怎么办 |
|---|---|---|---|
| 群居不动 | 土嘴、浜白 | 只在被靠近时动，几只挤在一起 | 从缝里过／整片绕开 |
| 先声后到 | 号吼 | 隔着很远就吼，方向感乱掉（debuff） | 听声辨位，提前让开 |
| 伏击 | 乙羽 | 收起来像一块破布，等你走到跟前 | 记位置，下次绕 |
| 出现即走 | 泣骸 | 哭一阵就走，有时间窗 | 等它走，或抢窗口 |
| 守株待兔 | 紅口縄 | **不追**，占住一段路，谁过打谁 | 只能绕或硬闯 |
| 心理攻击 | 喰怨語 | 会说话，说的是你心里那句（掉饥渴／理智） | 别听，快走 |
| 不可战胜 | 魂疑、未记录 | **追**，而且追得上 | 只能逃 |

**追／逃要接的东西**：

- **追**：怪的深度差会缩小（它向你移动）；追上 = 强制开打或直接咬一口
- **逃**：往上跑（按层扣血，这是现有的代价）或者跑出遭遇板边缘
- **灯是双刃**：圈越大你看得越远，**也越容易被看见**。这跟《暗黑地牢》正好相反
  （那边亮=安全、暗=多战利品），但更贴原作——深渊里点火就是在告诉东西你在这儿

### 12.17 方向改了：世界本身要变成格子（v2.1 · 讨论结论）

**B 被否掉了**：撞上才切进棋盘 = **事后反应**。而「躲」是**事前避让**——
要先看见它在那边，然后决定从另一边走。事后才给选择，那不叫躲，叫挨打之后选怎么挨。

要「事前避让」+「后面上视野」，只有一条路：**世界本身得有空间**。

好消息是这套东西本来就自洽：**魔塔就是格子迷宫**。世界、战斗、背包可以是同一套格子语言
（1×1 ~ 4×4 已经现成），三个地方共用一套规则，不用再发明第二套。

**新的形状：一条往下的竖井走廊**

```
    ▓▓▓▓▓▓▓▓▓     ▓ 岩壁（不可走）
    ▓ · · · ▓     · 可走
    ▓ · 你· ▓     怪 / 搜索点 / 哨站都是格子上的东西
    ▓ · □ □ ▓     □ 4×4 巨兽堵住整段
    ▓ · · ○ ▓     ○ 小东西，旁边留缝
    ▓▓▓▓▓▓▓▓▓
```

| 现在 | 改成 |
|---|---|
| 滚轮 = 连续下潜 | **滚轮 = 往下走一格**（肌肉记忆还在，只是变成一格一格） |
| 你在屏幕正中，横向没有意义 | 你在格子里，←/→ 横移，**从怪旁边绕过去就是躲** |
| 深度 = 滚动位置换算 | **深度 = 行号 × 每行米数**（一行先定 20 米） |
| 视野 = 没有 | 只揭示灯半径内的格子，其余全黑（下一步就做这个） |
| 搜索点 / 怪 = 飘在带子上的卡片 | 它们站在格子里，你得走过去或绕开 |

**能留下来的**（不用重做）：深度↔米↔补给消耗、背包、出发准备、结算、魔塔战斗算法、
哨站（变成走廊边的落脚点）、右侧剖面（改成小地图/进度条）、全部美术与 UI 语言。

**要重做的**：`virtual-scroll`（连续滚动 → 格子步进）、`dive-scroll` 的深度读数、
`field` / `road` 的定位（改成格子）、`self`（从"屏幕中心"变成"格子坐标"）。

**分三步走，每步都能玩**：

1. **竖井**：3 格宽的走廊能往下走，滚轮一格一格，深度照算，右下角小地图显示进度
2. **视野**：只看见灯半径内的格子，走过的地方留在小地图上
3. **活物**：怪进格子，先「不追」的（守株待兔型），再加会追的

**内容怎么来**：一条 1,000 行（20,000 米）的竖井不可能全手写。走廊**程序化铺**（蛇形摆动、
偶尔收窄、偶尔分叉），手工只放**六座哨站、五条记录、几件特级遗物**——也就是现在这些锚点。

### 12.18 第一步已经落地：竖井（v2.2）

`abyss/shaft.ts`。世界现在是一条往下的格子走廊：

| 项 | 值 |
|---|---|
| 一格 | 60px |
| 一格 = 多少米 | **20 米**（20,000 米 = 1,000 行） |
| 走廊宽 | 3 格（2/3/4 号道） |
| 厅 | 六座哨站各自上下各 4 行，张开成 7 格宽 |
| 石头 | 每行 17% 的概率落一块，1~2 行高 |

**走法**：滚轮 / ↑↓ / WS = 上下走一格；←→ / AD = 横移一格。
上下走时如果正前方是石头，会**自动往旁边让一格**（读起来像绕过一块石头）；
两边都堵死才会停。

**深度没有换引擎**：走一格就把页面滚到「这一格对应的深度」，
所以饥渴、上浮扣血、哨站、结算照旧吃 `dive:tick`，一行都没改。
换掉的只是「世界怎么表现」那张皮。

**两个必须解决的坑**（都踩了）：

1. **死胡同**：石头是逐行随机撒的，单行都留了缝，连起来却可能走不通
   （12 行只剩 2 号道、13 行只剩 4 号道，中间 3 号是石头，横着过不去）。
   现在生成完会**从头往下走一遍**，哪一行从上面够不着就拆掉挡路的石头。
2. **玩家小人被覆盖**：它原来和格子是同一个容器，`innerHTML` 一写就没了。
   现在分两层：`.shaft-world`（负责位移动画）里放 `.shaft-cells` 和 `.shaft-self`。

**暂时收起来的**：路上的搜索点（`field`）和怪（`road`）——它们现在还是按「深度」摆的浮动卡片，
放进格子世界会打架。等视野做完，它们按格子重新上（第三步）。

**还没接的**：哨站的「下潜口」在格子世界里怎么表现（现在靠 `dive:station-close` 之后自动往前蹬四步）。

### 12.19 参考《挖地小子》能学什么（v2.3 · 讨论）

原作是 2009 年的挖掘游戏（[百科](https://wapbaike.baidu.com/item/%e6%8c%96%e5%9c%b0%e5%b0%8f%e5%ad%90)），
核心循环：**挖 → 卖矿 → 升级装备 → 挖更深**，和我们已经有的那条线几乎一样。

**它的规则（值得抄的部分）**：

| 它的做法 | 我们现在的样子 | 该不该学 |
|---|---|---|
| **氧气**在洞里持续消耗，看深度数字判断「还回不回得去」 | 饥、渴两条值，手动吃喝 | **学**：压力应该是一个数，且和深度直接挂钩 |
| **只能往下/左右挖，挖不动的地方就是墙；向上只能「飞」** | 走廊是画好的，石头挡路 | **学**：地形该有「挖得动 / 挖不动」两档 |
| **脚不落地不能横挖** | 没有落地概念 | 学：横移前必须站在实地上（不然一路飘着走太像逛街） |
| **硬岩钻不透，得靠炸弹炸** | 石头完全挡死 | **学**：给「炸开一块石头」的消耗品，钱就有出口 |
| 矿物分级（黑 50 → 钻石 5,000） | 遗物六档 + 价格 | 已经有了 |
| 小地图 + 深度计 + 任务倒计时 | 有深度，没小地图；没有倒计时 | 小图**要**；倒计时**不要**（我们不是关卡制） |
| 每关尽头一个 BOSS 房 | 厅 + 守门兽 | 方向一致 |

**最大的启发：「挖」本身就是移动。**

它里面你不是「沿着通道走」，而是**把地形挖掉**——于是移动自带成本（时间/氧气），
而且**你挖过的路会永远留在那儿**：回去的路线、被追的路线，都是你自己挖出来的。

这一条直接对上我们现在的两个待办：

1. **视野**：没挖过的地方本来就是黑的——不用再额外编一套迷雾规则
2. **躲怪**：你能挖一条侧道绕过去；怪也能顺着你挖的路追上来（这条是《Dig Dug》的逻辑）

**建议的改法**：把「预设走廊」换成「可挖的土层」。

| 层 | 地形 | 玩法 |
|---|---|---|
| Ⅰ–Ⅱ | 松土为主 | 想怎么挖怎么挖，但**氧气/补给在烧** |
| Ⅲ–Ⅴ | 夹硬岩 | 只能沿裂隙走，硬岩挡路要么绕、要么炸 |
| Ⅵ–Ⅷ | 大片硬岩 + 少量空洞 | 走的是别人挖出来的路，而不是自己选的 |

**风险**：可挖的地形意味着「地图是玩家生成的」，存档、小地图、以及「怪从哪来」都要跟着改；
工作量比现在的程序化走廊大一截。所以建议**先只把一层（Ⅰ）改成可挖**，试出手感再往上铺。

### 13.1 一局跑什么

```
        [ ] [ ] [ ]     ← 第 1 行
         [ ] [ ]        ← 第 2 行：三选一，只能往下
          ...
         [楼梯]         ← 第 8 行往下 = 下一层
```

| 项 | 值 |
|---|---|
| 一层行数 | **8 行**（先都 8，以后再细分） |
| 每行节点 | **3 个**（偶尔 2 个，撑压强） |
| 一局时长 | 8 行 × 约 40 秒 ≈ 5~7 分钟，加回程与结算 ≈ **10 分钟** |
| 地图 | **每局重新生成** |
| 深度 | 层号 + 层内行号（20,000 米只当背景数字） |

### 13.2 节点类型

| 节点 | 里面 | 备注 |
|---|---|---|
| 战斗 | 一只或几只怪 | 打完掉遗物；复用现有的魔塔战斗 |
| 精英 | 大东西（3×3、4×4） | 掉好东西，也可能打不过 |
| 宝物 | 一件遗物，有守 | 值得绕路 |
| 商店 | 花钱买氧气 / 绳 / 炸弹 | 钱终于有出口 |
| 补给 | 氧气罐、口粮 | 决定你还敢走多远 |
| 事件 | 三选一（拿 / 不拿 / 赌） | 便宜、有味道、不需要战斗 |
| 楼梯 | 下一层 | **双向**：下去了还能爬回来 |

### 13.3 氧气（唯一的时钟）

- 进一个节点扣一次，**行数越深扣得越多**
- 三个来源：**提前备足**（起点买）、**中间搜**（补给房捡）、**补给房买**
- 归零 = 没力气了：每次行动掉血，很快就死

原来的饥渴两条值、灯火每层一支，全部并进氧气这一条。

### 13.4 撤离

- **一键回程结算**：按走过的行数扣氧气，然后掷**一次**「路上出了什么事」
- 事件：塌方掉一件 / 被咬掉血 / 撞见东西打一场 / 什么都没发生
- 氧气不够 = 死在回程，东西掉光
- 撤离点**固定在起点**（每层的入口），所以走得越深，回程越贵

### 13.5 楼梯是双向的

下去了还能原路爬回来，**但要吃「上层惩罚」**：越往上那一层，爬回去越贵（原作的上升负荷）。
所以「再下一层」是能反悔的——只是反悔要付钱。

**出发准备面板**（`abyss/prep.ts`）：0 米时屏幕下方浮出「出发准备」。里面是货架 + 你的背包：
选「一层/二层/三层/四层」→「买齐」，它按推荐数量一份份买进背包格子，钱和格子不够就停在够的地方。
面板底下还能买**背筐**（扩容）。

**背包扩容**：6×5 起，`背筐 7×5`（6,000）、`加固背筐 8×5`（14,000）、`探窟家的大背筐 8×6`（30,000）。

**按距离消耗**（`abyss/supply.ts`）：按「这一潜到过的最深」算，上浮再下潜不白吃也不退。
HUD 左下角多一行「粮 / 水 / 灯 / 药」，缺了就变红。

**为什么必须扩容**（实测数据）：

| 目标 | 补给占格 | 30 格还剩给战利品 |
|---|---|---|
| 一层 1,350 米 | 4 | 26 |
| 二层 2,600 米 | 8 | 22 |
| 三层 7,000 米 | 20 | 10 |
| 四层 12,000 米 | 23 | 7 |

四层只剩 7 格——一件 2×3 就没了。所以**深层要么先买背筐，要么靠哨站补货**（哨站加价补货还没做）。
